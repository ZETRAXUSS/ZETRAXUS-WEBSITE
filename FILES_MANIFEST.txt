DATABASE SCHEMA
===============
1. profiles
   - id (UUID, PK)
   - username (TEXT, UNIQUE)
   - display_name (TEXT)
   - bio (TEXT)
   - avatar_url (TEXT)
   - role (user | creator | admin)
   - created_at, updated_at (TIMESTAMP)

2. follows
   - follower_id (UUID, FK)
   - following_id (UUID, FK)
   - created_at (TIMESTAMP)
   - Constraint: No self-follows

3. forum_categories
   - id (UUID, PK)
   - name (TEXT)
   - slug (TEXT, UNIQUE)
   - description (TEXT)
   - created_at (TIMESTAMP)

4. forum_threads
   - id (UUID, PK)
   - author_id (UUID, FK)
   - category_id (UUID, FK)
   - title (TEXT)
   - body (TEXT)
   - created_at, updated_at (TIMESTAMP)

5. forum_replies
   - id (UUID, PK)
   - thread_id (UUID, FK)
   - author_id (UUID, FK)
   - body (TEXT)
   - created_at, updated_at (TIMESTAMP)

6. thread_likes
   - thread_id (UUID, FK)
   - user_id (UUID, FK)
   - created_at (TIMESTAMP)
   - PK: (thread_id, user_id)

7. reply_likes
   - reply_id (UUID, FK)
   - user_id (UUID, FK)
   - created_at (TIMESTAMP)
   - PK: (reply_id, user_id)

SETUP STEPS
===========
1. Create Supabase project at https://app.supabase.com
2. Get Project URL and Anon Key from Settings → API
3. Create .env.local with credentials
4. Copy /supabase/migrations/001_initial_schema.sql
5. Run in Supabase SQL Editor
6. Insert forum categories (see SUPABASE_SETUP.md)
7. Run: npm run dev
8. Test at http://localhost:3000
